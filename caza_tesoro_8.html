Objetivo

Encontrar 4 palabras clave escondidas en carpetas: 2 en esta computadora con Windows usando CMD y 2 en equipos Linux (192.168.10.104 y 192.168.10.110) a los que te conectarás por SSH con PuTTY. Cada palabra clave habilita la siguiente parte y al final obtienes tu calificación.

Dinámica: trabajo individual y sumativo. Cada parte vale 8 pts y cada error resta 2 pts.

PARTE 1 — Palabra clave 1 en Windows con CMD (8 pts)

Teoría rápida: CMD (Símbolo del sistema) es la consola de comandos de Windows. Con cd entras a una carpeta, con cd.. regresas, con dir ves su contenido (dir /a muestra también los archivos y carpetas ocultos) y con tree /f /a ves todo el árbol de carpetas y archivos. Con type lees un archivo de texto.
Instrucciones:
  1. Abre la consola: presiona Win + R, escribe cmd y presiona Enter.
  2. Busca por tu cuenta, usando tus conocimientos y tu destreza, la carpeta oculta que contiene el archivo de la palabra clave 1. No se te indica dónde está.
  3. Lee el archivo con type y escribe la palabra clave abajo.
Comandos que te pueden servir: dir /a (lista incluso lo oculto), cd (entrar a una carpeta), cd.. (regresar), tree /f /a (árbol de carpetas y archivos), dir /s /b /a (busca dentro de todas las subcarpetas) y type (muestra un archivo de texto). Decide tú por dónde empezar.

⚠️ Debes ingresar tu Nombre y Grado y presionar "Guardar Datos del Estudiante" antes de continuar.

PARTE 2 — Palabra clave 2 en Windows con CMD (8 pts)

Sigues en CMD. La segunda palabra clave está en otra carpeta oculta del equipo, más escondida que la primera. Busca por tu cuenta con los comandos que ya conoces; no se indica la ubicación.

PARTE 3 — Palabra clave 3: SSH con PuTTY al Linux 192.168.10.104 (8 pts)

Teoría rápida: SSH es un protocolo que permite controlar otro computador de forma remota y segura desde la línea de comandos. PuTTY es el programa de Windows que usamos para conectarnos por SSH. Una vez dentro, trabajas con comandos de Linux: pwd (dónde estoy), ls -a (lista incluso lo oculto; los ocultos empiezan con punto), cd (entrar a carpeta) y cat (leer un archivo).
Conexión con PuTTY:
  1. Abre PuTTY.
  2. En Host Name (or IP address) escribe 192.168.10.104, Port 22 y Connection type SSH.
  3. Presiona Open. Si aparece una alerta de seguridad, presiona Accept.
  4. Inicia sesión con los datos de abajo (al escribir la contraseña no se ve nada, es normal).

Datos de conexión:

Host Name: 192.168.10.104
Port: 22  |  Connection type: SSH
Usuario: cep
Contraseña: code2026

Ya dentro del equipo Linux, busca por tu cuenta la carpeta oculta con la palabra clave 3. No se indica dónde está.

Comandos que te pueden servir: pwd, ls -a (incluye ocultos, que empiezan con punto), ls -R (todas las subcarpetas), cd, cat y find. Cuando termines, escribe exit para cerrar la sesión.
