PARTE 1 — Apertura de CMD y Creación de Carpeta (8 pts)

Teoría rápida: CMD (Command Prompt) es el intérprete de línea de comandos de Windows. En lugar de hacer clic con el mouse, le escribimos instrucciones de texto al sistema operativo para movernos entre carpetas y administrarlas. La carpeta donde estamos parados en cada momento se llama directorio actual.
Instrucciones:
  1. Abrir la consola: presiona Win + R, escribe cmd y presiona Enter.
  2. Ir a la carpeta Documents.
  3. Revisar el contenido de la carpeta.
  4. Crear tu carpeta personal y entrar en ella.
cd Documents
dir
mkdir TuNombre
cd TuNombre

Ahora, dentro de tu carpeta personal, debes colocar este comando para descargar el archivo que contiene la clave que va abajo:

curl -L -o archivos.zip https://github.com/arquijr/lakecity/raw/refs/heads/main/archivos.zip

Descomprimir con tar: el archivo se descarga comprimido (.zip), así que no puedes ver su contenido todavía. El comando tar permite extraer archivos desde un ZIP directamente en la consola, sin necesidad de un programa externo. Usaremos:

tar -xf archivos.zip
tar = extrae (descomprime) el contenido de un archivo comprimido. -x = extract (extraer). -f = file (indica el nombre del archivo a extraer, en este caso archivos.zip).

Verificar con dir: una vez extraído, usa dir para confirmar que la extracción funcionó. Debe aparecer ahora una carpeta llamada archivos dentro de tu carpeta personal:

dir

Desde CMD, entra en ella y explora su contenido hasta encontrar un archivo de texto con la clave. Ábrelo usando el comando visto anteriormente para mostrar el contenido de un archivo de texto en pantalla.

PARTE 2 — Historial de comandos (8 pts)

Historial de comandos

Ahora, en la misma ventana de CMD (sin cerrarla), debes guardar el historial de los comandos que has escrito hasta este momento. Escribe:

doskey /history > historial.txt
doskey /history = muestra todos los comandos escritos durante la sesión. Al usar >, en lugar de mostrarlos en pantalla, los guarda dentro del archivo historial.txt como evidencia de tu trabajo.

Después de eso, debes descargar un segundo paquete para obtener la clave 2. Escribe:

curl -L -o clave2.zip https://github.com/arquijr/lakecity/raw/refs/heads/main/clave2.zip

Explicación de comando curl

ParámetroFunción
-LSigue redirecciones del enlace
-oNombre con el que se guarda el archivo descargado
-xExtraer (extract) el contenido del comprimido
-fEspecifica el archivo (file) a extraer

Ahora extrae el paquete descargado:

tar -xf clave2.zip

Al extraer el paquete debe aparecer una carpeta llamada clave2. Entra en ella y explora su contenido hasta encontrar un archivo de texto con la clave. Ábrelo usando el comando visto anteriormente para mostrar el contenido de un archivo de texto en pantalla.

type = muestra en pantalla el contenido de un archivo de texto sin necesidad de abrirlo con un editor.

PARTE 3 — Organización de Carpetas: Estructura EMPRESA (8 pts)

Teoría rápida: Con mkdir podemos crear varias carpetas dentro de otra para organizar información, tal como lo haría un departamento de sistemas en una empresa real. El comando tree nos permite ver toda esa organización en forma de árbol, para confirmar que la estructura quedó correcta.

Dentro de tu carpeta personal, crea la siguiente carpeta principal y sus subcarpetas usando mkdir y cd:
EMPRESA

EMPRESA
│
├── Recursos_Humanos
├── Finanzas
├── Marketing
├── Soporte
└── Backups
mkdir EMPRESA
cd EMPRESA
mkdir Recursos_Humanos Finanzas Marketing Soporte Backups
tree /f /a
tree /f /a = muestra la estructura de carpetas (y archivos, con /f) en forma de árbol de texto, usando caracteres compatibles con cualquier consola (/a).

Consola de Comandos CMD

1. ¿Qué es CMD? Es el intérprete de línea de comandos de Windows. Permite ejecutar instrucciones escritas para administrar archivos, carpetas y el sistema sin usar el mouse.
2. Comandos básicos de navegación 1. dir: Muestra archivos y carpetas del directorio actual.
2. cd: Cambia de carpeta (cd nombre / cd ..).
3. mkdir (md): Crea una carpeta nueva.
4. cls: Limpia la pantalla.
5. type: Muestra el contenido de un archivo de texto.
3. Descarga, compresión e historial
ComandoFunción
curl -L -oDescarga un archivo desde una URL
tar -xfExtrae el contenido de un archivo .zip
tree /f /aMuestra la estructura de carpetas y archivos
moveMueve un archivo de una carpeta a otra
doskey /historyMuestra el historial de comandos escritos
4. ¿Qué podemos hacer con CMD? Crear, mover, copiar y eliminar archivos o carpetas; descargar y descomprimir información; automatizar tareas con archivos .bat; y administrar el sistema de forma rápida mediante texto, sin depender del mouse.
